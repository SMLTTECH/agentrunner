# Подключаемые инструменты (пакеты инструментов)

Тема 1 [классификатора](../%D0%9A%D0%BB%D0%B0%D1%81%D1%81%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%82%D0%BE%D1%80.md). Связанная тема — [Ядро](yadro.md): там описано, как агент вызывает любой инструмент.

## Суть

Агент действует только через **инструменты**: произвольный код модель выполнить не может. Часть инструментов
встроена в ядро ([каталог](yadro.md#встроенные-инструменты)), остальные подключаются **пакетами** — без
пересборки расширения `AgentRunner.cfe`.

**Пакет** — дополнительная обработка БСП (`.epf`) с командой-маркером `ar_ToolPack` и тремя функциями в модуле объекта:

| Функция | Назначение |
|---------|------------|
| `ar_ОписаниеИнструментов()` | манифест: пространство имён, версия, инструменты, настройки |
| `ar_ВыполнитьИнструмент(ИмяTool, АргументыJSON, Контекст)` | исполнение вызова, ответ — JSON-строка |
| `ar_ИсполнитьПодтверждённыйИнструмент(…)` | отложенная запись после подтверждения оператором (нужна, если есть изменяющие инструменты) |

Путь через форк `ar_ИнструментыПереопределяемый` тоже существует, но требует пересборки расширения; пакеты нужны,
когда инструменты привязаны к конфигурации или сервису и должны обновляться отдельно (`buh_*`, `files_*`).

## Как работает

**Регистрация** — форма «Пакеты инструментов», только по действию администратора (при старте системы пакеты не
подхватываются):

1. «Найти пакеты инструментов» — запрос к справочнику БСП по маркеру `ar_ToolPack`; сам поиск `.epf` не загружает.
   Манифест кандидата форма читает и проверяет дополнительно.
2. «Установить» — ядро вызывает `ar_ОписаниеИнструментов`. Для пакета с отключённым безопасным режимом форма просит
   дополнительное подтверждение.
3. Манифест проверяется целиком: любая ошибка — отказ всему пакету, частичной регистрации нет.
4. Запись пакета и инструментов в реестр — одной транзакцией; затем пересчёт доступности и создание недостающих настроек.

**Вызов**: цикл агента → движок прав → диспетчер → шлюз к пакету → `ar_ВыполнитьИнструмент`. Исключение внутри пакета
превращается в `{"error": …}`, агент продолжает работу. Если по режиму автономии или флагу инструмента нужно
подтверждение, **цикл ставит действие в очередь сам, до вызова пакета**; инструмент, получивший управление,
ставит в очередь только черновики и записи, которые режим разрешил (см. [Ядро](yadro.md#права-вызова)).

**Подтверждение**: изменяющий инструмент не пишет в базу сам — ответ `approval_id` + `pending_approval`. После решения
оператора ядро вызывает исполнитель пакета; он пишет в транзакции и возвращает `{Выполнено, DocumentRef, Сообщения}`.

**Контроль изменений**: «Проверить изменения» сверяет хеш манифеста; при расхождении пакет получает статус
«ТребуетПереподтверждения», его инструменты недоступны до «Переподтвердить». «Отключить» выключает инструменты,
история вызовов остаётся.

## Уровни риска

| Уровень | Подтверждение | Смысл |
|---------|---------------|-------|
| `Чтение` | нельзя требовать | только чтение |
| `Черновик` | по решению автора | готовит черновик, ничего не проводит |
| `Запись` | обязательно; исключение — явное `ОбоснованиеЗаписиБезПодтверждения` | изменяет данные |
| `Фиксация` | обязательно, без исключений | необратимое действие |

## Правила автора пакета

- Имя инструмента начинается с пространства имён пакета (`[a-z][a-z0-9_]{1,30}`, уникальное): `demo_echo`, `buh_…`.
- Манифест — схема **2**; пакеты со старыми ключами отклоняются (`legacy_manifest_keys`).
- Без `Выполнить()` и `Вычислить()`; диспетчеризация внутри пакета — условиями.
- Изменяющий инструмент ставит действие в очередь (`ar_Подтверждение.Поставить`), а не пишет сам.
- Секреты и ПДн в ответах и журнале маскируются; пользовательские тексты — через `НСтр`.
- `БезопасныйРежим = Ложь` допустим, но фиксируется в журнале и аудите (`package_registered_unsafe`);
  подписи и контрольные суммы `.epf` ядро не проверяет — за источник отвечает администратор.

## Частые отказы регистрации

| Код | Причина |
|-----|---------|
| `package_contract_violation:ar_ОписаниеИнструментов` | нет функции манифеста или она упала |
| `manifest_not_structure` | манифест — не структура |
| `legacy_manifest_keys` / `unsupported_schema_version:<N>` | схема не 2 — пересобрать пакет |
| `invalid_namespace` / `namespace_collision` | неверное или занятое пространство имён |
| `package_has_no_tools` | нет инструментов |
| `name_not_namespaced:<имя>` | имя без префикса пространства имён |
| `invalid_risk_level:<имя>` / `approval_required_for_risk:<имя>` | неверный риск или сочетание с подтверждением |
| `invalid_package_settings` | некорректные настройки пакета |

Механизм недоступен целиком: `subsystem_missing` (нет подсистемы БСП) или `functional_option_disabled`.
